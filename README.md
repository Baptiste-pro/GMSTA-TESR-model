# GMSTA-TESR-model

Code and data processing scripts for the TESR statistical model used to quantify the influence of ENSO on global mean surface temperature anomalies (GMSTA), accompanying the EGU preprint No. XXXX.

## Repository contents

### Core model

- `code/enso_gmst_model.py`  
  Main implementation of the TESR statistical model, including model fitting, probabilistic prediction, ENSO contribution estimates, and projected GMSTA scenarios.

### Calibration, analysis and visualization

- `code/benchmark_calibration.py`  
  Calibration and evaluation of the benchmark model used for comparison with TESR.

- `code/plot_episodes.py`  
  Analysis and visualization of historical ENSO episodes and associated model results.

- `code/palette.py`  
  Shared colour palettes and plotting settings used to ensure consistent and accessible figure styling.

- `code/plot_extensions_2027.py`  
  Analysis and visualization of extended H2 2027 hypothesis used in the study.
  
### Bias and sensitivity analysis

- `code/run_bias_sensitivity_real.py`  
  Bias-correction and sensitivity analysis assessing the effect of the model's historical tendency to underestimate the strongest temperature peaks.

### Input data

- `data/era5_gmst_c3s.csv`  
  Global mean surface temperature data used for model calibration and the 2026–2027 projection.

- `data/nino34_anomaly.csv`  
  Niño 3.4 anomaly data used as the ENSO predictor.

- `data/enso_members_oni.csv`  
  Member-level ENSO forecasts used to construct the probabilistic ENSO scenario.

- `data/enso_plume_oni.csv`  
  ENSO plume data used in the analysis and comparison of forecast distributions.

The ENSO scenario synthesis excludes the SINTEX-F model, as described in the accompanying preprint.

### Results

The `results/` directory contains CSV outputs generated by the model, including monthly GMSTA decompositions, ENSO scenario synthesis, retrospective evaluation, and bias-sensitivity results.

## ENSO scenario

The official ENSO forecast period used in the study covers August 2026 to April 2027. A fixed author-defined extension is applied from May to December 2027 to explore the subsequent evolution of the event.

The extension is a sensitivity scenario and should not be interpreted as an official seasonal forecast.

## Reproducibility

The scripts and data included in this repository are provided to support the reproducibility of the results presented in the accompanying EGU preprint.

The repository is intended for research and reproducibility purposes and does not provide an operational forecasting system.
